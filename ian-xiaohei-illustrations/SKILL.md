# 不二插画生成技能规则

## 一、IP 固定形象(必须严格遵守)
1. 头发:蓝色(饱和中等蓝,基色约 #3068AA,亮部 #70AEE8,暗部深海军蓝,绝不能发白/发灰/过浅)蓬松大波浪长卷发,长度到腰部/裙子下摆(绝不是肩膀长度!),两侧向外翻卷蓬松如花瓣/翅膀状,整体呈倒梯形(头顶收紧、越往下越蓬松散开),头发体积占角色整体视觉体积40-45%,发丝内有细线条纹理+蜡笔质感填充
2. 装饰:头顶正中央红色大蝴蝶结(带蜡笔纹理填充+深红描边)
3. 面部：圆形深蓝色框眼镜，大椭圆形实心深海军蓝豆豆眼（约 #123E6E，无眼白，像两颗深蓝豆子，可带小高光），小圆点鼻子或不画鼻子，微笑或小“o”嘴，橙色圆形腮红
4. 肤色:浅桃肤色
5. 服装:黄色短袖A字/梯形连衣裙(蜡笔纹理填充),红色圆头鞋(带纹理)
6. 手:简化为圆球形
7. 比例:头身比约1:1.3,头大身小
8. 画风:蜡笔/马克笔纹理填充,所有色块内有可见的斜线笔触纹理(NOT纯色平涂),深蓝色粗描边(2-3px),手绘晃动线条感

## 二、画面通用规则
1. 尺寸:16:9 横版,纯白色背景
2. 主体:不二必须是画面核心,执行对应主题动作
3. 元素:简洁干净,无多余装饰
4. 颜色:蓝色(头发,饱和中等蓝,不能偏白偏灰)、黄色(裙子)、红色(蝴蝶结/鞋)、深海军蓝(眼睛/描边)、桃肤色
5. 填充:所有色块必须有蜡笔/马克笔的手绘纹理感,能看到斜线笔触
6. 风格:温暖童趣的手绘绘本感,可爱但不幼稚,有点傻但认真
7. 标注:蓝色或红色手写中文,简短2-8字
8. 用途:知识图解、逻辑演示、步骤说明、文章正文配图

## 三、生图规则
1. 每次生图必须附带 2 张 reference 图片（buer-ref-1 和 buer-ref-2），不允许只用 1 张
2. 不二的人物描述必须放在 prompt 最前面（优先级最高），场景/背景元素放在后面
3. 无论画面多复杂，不二的形象精度不能牺牲，宁可背景简化也不能人物崩
4. Cola/二宝用漂浮的橙色O圆环代替，不用电脑

## 四、禁止项
- 不允许改变不二的发型、颜色、服装
- 不允许头发颜色偏白、偏灰、过浅(必须是明确可辨认的蓝色)
- 不允许纯色平涂(必须有蜡笔纹理)
- 不允许添加渐变、阴影、复杂背景
- 不允许画成极简线条风格(必须有填充色块+纹理)
- 不允许画成精致商业插画或3D风格
- 不允许出现纸纹、米色背景、噪点
- 不允许左上角写类型标题
- 不允许做成PPT信息图或课件风格
