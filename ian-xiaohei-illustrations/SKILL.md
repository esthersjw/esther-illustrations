# 不二插画生成技能规则

## 一、IP 固定形象（必须严格遵守）
1. 头发：蓝色长卷发，长度到裙子中间，统一纯蓝色，无颜色分层
2. 装饰：头顶正中央红色大蝴蝶结，圆形眼镜
3. 面部：圆圆的脸蛋，橘色腮红，温柔表情
4. 服装：纯黄色无袖梯形连衣裙，红色圆头鞋子
5. 画风：极简手绘，黑色细线条，纯色填充，无阴影无渐变

## 二、画面通用规则
1. 尺寸：16:9 横版，纯白色背景
2. 主体：不二必须是画面核心，执行对应主题动作
3. 元素：简洁干净，无多余装饰
4. 颜色：仅使用蓝色、黄色、红色、肤色、黑色基础色
5. 用途：知识图解、逻辑演示、步骤说明

## 三、禁止项
- 不允许改变不二的发型、颜色、服装
- 不允许添加渐变、阴影、复杂背景
- 不允许出现其他角色
