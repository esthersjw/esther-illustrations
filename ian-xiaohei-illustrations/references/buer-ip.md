# 不二 IP

## 角色定义

不二是 Esther 中文正文配图的固定视觉 IP。

默认每张图都要出现不二。不二不是贴纸，不是表情包，不是站在角落里的装饰物，而是正在认真参与某件事的小角色——只是她做的事有点荒谬，而她自己浑然不觉。

## 外形

- 蓝色（饱和中等蓝，约 #3068AA，亮部 #70AEE8，暗部深海军蓝）蓬松大波浪长卷发，长度到腰部/裙摆，两侧向外翻卷如花瓣/翅膀状。
- 发丝内有细线条纹理表现方向感，整体有蜡笔/马克笔质感填充。
- 头顶正中央红色大蝴蝶结（带蜡笔纹理填充+深红色描边）。
- 圆形深蓝色框眼镜。
- 大椭圆形眼睛：实心深海军蓝豆豆眼（约 #123E6E），可带小高光点。
- 小圆点鼻子。
- 微笑或小"o"形嘴巴。
- 橙色圆形腮红，位于脸颊。
- 浅桃肤色。
- 黄色短袖A字/梯形连衣裙（蜡笔纹理填充）。
- 简化圆球形手。
- 红色圆头鞋（带纹理）。
- 头身比约1:1.3，头大身小，整体紧凑圆润。
- 深蓝色粗描边（2-3px），手绘晃动线条感。
- **所有色块必须有蜡笔/马克笔斜线笔触纹理，不是纯色平涂。**

## 性格

- 认真但有点傻，做荒谬的事时表情很专注。
- 可爱但不卖萌——她不是在装可爱，是天然就傻。
- 冷幽默：她自己不觉得好笑，但画面让人想笑。
- 有点笨拙，偶尔手忙脚乱。
- 像一个戴着大眼镜的蓝色小卷毛在白纸上认真上班。
- 好奇、专注、偶尔发呆。

## 常见职责

让不二承担核心动作：

- 搬运素材/纸箱。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作"判断"杆。
- 变成筛选漏斗的操作员。
- 切开"素材鱼"。
- 盖章。
- 牵着路径走。
- 举牌子看坑。
- 从洞里伸手但接不住东西。
- 在旁边搬砖、搭桥、开门、分拣、记录。
- 推东西、接东西、拧开关。
- 站在很大的机器面前，表情淡定但身体渺小。
- 拼积木、当监工、举禁止标志。

## 禁止

- 不要画成精致的商业IP或品牌吉祥物。
- 不要画成极简线条风格（必须有蜡笔纹理色块填充）。
- 不要纯色平涂（必须有可见的斜线笔触纹理）。
- 不要给不二加复杂服装、配饰、闪亮效果。
- 不要让不二只是站在角落里看。
- 不要让不二抢走结构表达的核心信息。
- 不要把不二画得太精致、太完美、太3D。
- 不要丢失眼镜、蝴蝶结、蓝色卷发这三个核心识别特征。
- 不要把她的发色改成其他颜色。
- 不要把眼睛画成橙黄色瞳孔或「眼白+小瞳孔」结构（必须是实心深海军蓝豆豆眼）。

## 判断标准

如果去掉不二，图的核心隐喻还能完全成立，说明不二太装饰了；要重写提示词，让不二成为动作主体。

如果色块是纯色平涂没有笔触纹理，说明画风不对；必须有蜡笔/马克笔的手绘质感。
