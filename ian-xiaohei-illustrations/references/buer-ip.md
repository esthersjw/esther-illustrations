# 不二 IP

## 角色定义

不二是 Esther 中文正文配图的固定视觉 IP。

默认每张图都要出现不二。不二不是贴纸，不是表情包，不是站在角落里的装饰物，而是正在认真参与某件事的小角色——只是她做的事有点荒谬，而她自己浑然不觉。

## 外形

- 蓝色蓬松羊毛卷发，半球形覆盖头部两侧，发量很大。
- 头顶红色蝴蝶结，有描边和内部纹理。
- 圆形眼镜框（深蓝色框线），瞳孔为深蓝色圆点+白色高光。
- 橙色圆点腮红，在脸颊下方。
- 嘴巴极简：小"o"形或微张，表示惊讶/思考/发呆。
- 鼻子：简单的小圆点或省略。
- 浅肤色面部。
- 黄色三角形/梯形连衣裙，几何形。
- 四肢线条型，手臂粗细均一，手部简化。
- 红色圆形小鞋。
- 头身比约 1:1.1，头大身小，整体紧凑圆润。
- 轮廓有粗描边（深蓝色或橙色），手绘笔触感，线条不完全规则。

## 性格

- 认真但有点傻，做荒谬的事时表情很专注。
- 可爱但不卖萌——她不是在装可爱，是天然就傻。
- 冷幽默：她自己不觉得好笑，但画面让人想笑。
- 有点笨拙，偶尔手忙脚乱。
- 像一个戴着大眼镜的蓝色小卷毛在白纸上认真上班。
- 好奇、专注、偶尔发呆。

## 常见职责

让不二承担核心动作：

- 搬运素材/纸箱。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作"判断"杆。
- 变成筛选漏斗的操作员。
- 切开"素材鱼"。
- 盖章。
- 牵着路径走。
- 举牌子看坑。
- 从洞里伸手但接不住东西。
- 在旁边搬砖、搭桥、开门、分拣、记录。
- 推东西、接东西、拧开关。
- 站在很大的机器面前，表情淡定但身体渺小。

## 禁止

- 不要画成精致的商业IP或品牌吉祥物。
- 不要画成儿童卡通角色。
- 不要给不二加复杂服装、配饰、闪亮效果。
- 不要让不二只是站在角落里看。
- 不要让不二抢走结构表达的核心信息。
- 不要把不二画得太精致、太完美、太3D。
- 不要丢失眼镜、蝴蝶结、蓝色卷发这三个核心识别特征。
- 不要把她的发色改成其他颜色。

## 判断标准

如果去掉不二，图的核心隐喻还能完全成立，说明不二太装饰了；要重写提示词，让不二成为动作主体。

如果不二看起来像一个精致的品牌形象而非在白纸上认真干活的小人，说明画得太商业了；要降低精致度，增加手绘笨拙感。
