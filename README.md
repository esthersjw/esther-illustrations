# 不二 Illustrations
专为豆包 Codex 打造的专属插画技能

## 项目介绍
默认视觉 IP 是「不二」：一个拥有蓝色长卷发、头顶红色蝴蝶结、佩戴圆框眼镜、身穿黄色梯形连衣裙、搭配红色圆头鞋的软萌女孩。
采用极简手绘风格，适合用于知识讲解、逻辑演示、PPT配图。

## 视觉规范
- 比例：16:9 横版
- 背景：纯白色
- 风格：柔和蜡笔手绘，纯色填充无渐变
- 角色：不二必须作为核心主角，参与画面动作
- 批注：角落可添加蓝色简约手写中文
